# 🌍 智慧旅遊行程規劃助手 (Smart Travel Planner)

一個輕量、流暢、跨平台（桌面 / 手機 / PWA 應用程式），支援離線運作、Firebase 雙向即時雲端同步、旅伴公開投票與討論、Notion 風格橫向多天看板、手機雙指縮放、多國語言小卡與全球 10 國即時匯率分帳的現代化旅遊行程規劃系統。

## ✨ 核心特色功能

### ✈️ 1. 多目的地分頁規劃
- **靈活行程管理**：隨時新增、重新命名或刪除不同的旅遊計畫（如：東京、大阪、首爾、歐洲等）。
- **特色 Emoji 圖示**：內建各大洲與特色分組的旅遊 Emoji 選單（亞洲、歐洲、美洲、非洲探險等），輕鬆標示旅程特色。
- **雙端自適應導航**：桌面端支援平滑水平滾動標籤列；手機端自動收合為下拉式快速切換選單，且選單末端貼心配備「➕ 新增旅遊目的地分頁...」捷徑。
- **彈性複製現有分頁**：支援複製其他分頁的景點與行程；在複製項目中可自訂選擇是否**「複製景點的『已拜訪/未拜訪』狀態、投票結果與評論」**。若取消勾選，新分頁之景點自動初始化為**「未拜訪」**且**無投票與評論紀錄**，打造全新無負擔的旅行計畫！

### 🗓️ 2. 全新「全部日程」橫向看板檢視（Notion Board View）
- **由左至右橫向天數排序**：點擊側邊欄「全部日程」時，自動切換為現代化看板視圖，Day 1 至 Day N 依序自左向右排列，直觀瀏覽整體旅遊節奏。
- **雙向滾動控制**：配備頂部高辨識度反色滾動條（青綠漸層）與底部滾動條，兩者即時雙向連動，無論瀏覽看板頂部或底部皆可隨意捲動。
- **緊湊排版與即時連動**：行程卡片與「+ 新增行程項目」按鈕緊貼各天行程末端，去除多餘留白；在全部日程中新增或修改項目，單日行程分頁自動毫秒級同步。

### 🔍 3. 手機端專屬：多級看板縮放與雙指捏合（Pinch-to-zoom）
- **3 級自訂視圖切換**（手機專屬控制列）：
  - **`⊞ 雙欄 (縮小)`**：50% 寬度緊湊檢視，一螢幕同時看連續兩天行程，掌握大局。
  - **`▢ 標準`**：82vw 適中欄寬，保留右側邊緣 Peek 提示，兼顧細節與滑動流暢度。
  - **`➕ 放大`**：92vw 滿版大字與寬裕間距，方便行走中清晰檢視時間與地點。
- **支援手機雙指手勢捏合（Pinch-to-zoom）**：直接在手機螢幕上以雙指張開或縮小，自然切換縮放比例，並自動儲存個人偏好設定。

### 📱 4. 手機觸控體驗最佳化（全向自然滑動）
- **上下垂直滾動與左右橫向切換並行**：優化觸控事件（`touch-action: pan-x pan-y`），使用者在手機上觸碰行程卡片時，既能順暢上下滾動瀏覽整頁，亦能左右橫拉切換天數，徹底解決手機網頁滾動手勢衝突。
- **側邊欄抽屜零跳動**：行動端初始載入時側邊抽屜以收合狀態渲染，點擊漢堡選單（`≡`）即平滑滑出，操作手感貼近原生 App。

### 🌐 5. 實用旅行小助手 (Travel Assistant Add-on)
- **多國語言小卡 (`language_cards.html`)**：
  - 整合**日語（🇯🇵）**、**韓語（🇰🇷）**、**英語（🇺🇸）**三大熱門旅遊語系。
  - 涵蓋「基本禮貌、餐飲美食、購物退稅、交通問路、公共設施、飯店住宿」六大常用情境。
  - 支援動態點詞組句、中文注音諧音、國際音標/羅馬拼音、HTML5 真人語音朗讀（Web Speech API）。
  - 配備**全螢幕大字模式**，遇到溝通困難時可直接旋轉螢幕出示給當地店家或路人觀看。
- **全球 10 大熱門貨幣即時換算與旅伴分帳計算器**：
  - 完整支援 10 大貨幣：**日圓 (JPY)、韓元 (KRW)、美金 (USD)、歐元 (EUR)、英鎊 (GBP)、澳幣 (AUD)、加幣 (CAD)、瑞士法郎 (CHF)、人民幣 (CNY)、港幣 (HKD)**。
  - 以「新台幣 1 元 (1 TWD)」為基準自動連網抓取最新牌告匯率（支援離線本機快取與手動自訂匯率）。
  - 即時雙向外幣與新台幣換算，並提供台灣銀行與 Google Finance 官方即時外匯查詢捷徑。
  - 內建**旅伴快速平攤分帳計算器**，輸入消費總額與分攤人數，即時換算每人應付外幣與折合新台幣。
- **外部旅行 App 智慧串聯**：一鍵開啟 Google Maps 路線導航、Visit Japan Web 日本官方入境申報、食べログ (Tabelog) 日本美食評分、NAVITIME 日本鐵路交通規劃、台灣銀行牌告匯率。
- **側邊欄與懸浮按鈕雙入口**：漢堡選單內建專屬入口，畫面右下角配置炫彩毛玻璃懸浮按鈕 (FAB)。

### 🎨 6. 雙主題設計：微紫透明玻璃感（淺色）與深邃夜間模式（深色）
- **淺色模式（Light Theme）**：微紫透明玻璃質感（Soft Violet & Glassmorphism），具備毛玻璃磨砂（Backdrop blur）、柔和陰影與淡雅紫光光澤，帶來繽紛明亮且高級的視覺感受。
- **深色模式（Dark Theme）**：維持經典深邃夜間配色，高對比不刺眼，低光源環境下使用舒適省電。

### 👍 7. 景點雙維度意向與心得投票
- **未造訪景點**：提供「👍 想去」與「👎 不想去」投票，統計行前偏好。
- **已造訪景點**：鎖定行前意向，新增「⭐ 造訪心得：👍 喜歡 / 👎 不喜歡」評分，完整保留歷史意向數據。
- **具名投票清單抽屜**：點擊「👥 名單」即時展開投票旅伴名冊，分組查閱造訪心得與行前意向。

### 🔐 8. 權限模式與資料安全
- **唯讀模式（預設）**：所有旅伴皆可自由檢視行程、查看景點、簽到、投票與留言討論。
- **管理員編輯模式**：輸入管理員通行密碼即可解鎖新增、編輯、拖曳調整、排序與刪除行程資料的完整權限。
- **雙向即時雲端同步**：串接 Firebase Realtime Database，任何編輯或投票異動即時同步至所有在線成員螢幕。
